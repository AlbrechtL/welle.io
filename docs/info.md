# About welle.io

welle.io is a DAB and DAB+ software defined radio (SDR). It runs on Windows,
Linux, macOS and embedded devices like the Raspberry Pi 2 and newer.

The goal is an easy to use DAB software radio.

welle.io was forked in 2017 from dab-rpi and sdr-j-dab, which are now
[qt-dab](https://github.com/JvanKatwijk/qt-dab). It also uses code from the
[dablin](https://github.com/Opendigitalradio/dablin) project.
