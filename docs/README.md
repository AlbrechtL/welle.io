Development
===
You can join the development by forking welle.io and sending pull requests.

* [Translating welle.io](translating-welle-io.md)  
Are you not a programmer, you can contribute to the project by translating welle.io in your native language. Please visit the page [Translating welle.io](translating-welle-io.md).
* [Website](website.md)  
The welle.io website is hosted via GitHub pages and you are welcome to create pull requests.
* Flatpak   
You can find the flatpak repo here: https://github.com/flathub/io.welle.welle-gui
