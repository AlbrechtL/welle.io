# User guide

welle.io is an open source DAB and DAB+ software defined radio (SDR). All you
need is an SDR, e.g. a cheap rtl-sdr USB stick, and an antenna for DAB
Band III.

* [Installation](installation.md): packages for Windows, Linux, macOS and
  FreeBSD, nightly builds
* [Usage](usage.md): command line options and keyboard shortcuts
* [Supported hardware](../devices/index.md): set-up of rtl-sdr, Airspy,
  rtl_tcp, SoapySDR and raw files
* [FAQ](../faq.md): hardware requirements, settings and more
* [welle-cli](welle-cli.md): the command line tool and its
  [web interface](welle-cli-web-interface.md)

If you found a bug or need help, please open an
[issue on GitHub](https://github.com/AlbrechtL/welle.io/issues).
