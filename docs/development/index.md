# Development

**Any contributions and pull requests are welcome!** You can join the
development by forking welle.io on
[GitHub](https://github.com/AlbrechtL/welle.io) and sending pull requests.
Please take a look at the
[issues](https://github.com/AlbrechtL/welle.io/issues), but new ideas are
welcome too.

## Contributing

* [Building](building.md): build welle.io and welle-cli on Linux, Windows
  and macOS
* [Translating welle.io](translating-welle-io.md): not a programmer? You can
  translate welle.io into your native language.
* [Code conventions](code-conventions.md)
* [Website](website.md): this website is built from the `docs/` folder of
  the repository, and you are welcome to improve it.
* Flatpak: the Flatpak repository is
  [flathub/io.welle.welle-gui](https://github.com/flathub/io.welle.welle-gui).
