# Code conventions

welle-io contains code from different origins, and that were subsequently modified by several authors. In its present state, it shows an eclectic choice of styles and feels a bit like a patchwork.

We agree that pushing towards a consistent code style is a good thing, and encourage contributors to follow the following guidelines:

- [Stroustroup indentation style](https://en.wikipedia.org/wiki/Indentation_style#Variant:_Stroustrup)
- [CPP Core Guidelines](http://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines#main)

Following these guidelines is less important than keeping existing working code functional, and the plan is not to rewrite everything according to these guidelines. However, when modifying and/or adding new code, keep these guidelines in mind.
